## 📖 Overview

**Lumina AI Tutor** is an AI-powered educational assistant designed to make learning interactive, personalized, and engaging. Instead of simply providing answers, Lumina explains concepts, answers questions, assists with problem-solving, and adapts to different learning styles using Google's Gemini models. The project is positioned as an early-stage prototype built to explore AI-assisted education and prompt engineering. :contentReference[oaicite:0]{index=0}

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/RUSHIT305/lumina-ai-tutor-.git

cd lumina-ai-tutor-
```

---

## Install Frontend

```bash
cd frontend

npm install

npm run dev
```

---

## Install Backend

```bash
cd backend

pip install -r requirements.txt

uvicorn main:app --reload
```

---

# 🔑 Environment Variables

Create a `.env` file inside the backend folder.

```env
GEMINI_API_KEY=YOUR_API_KEY

SECRET_KEY=YOUR_SECRET_KEY
```

---

# 🧠 How It Works

1. User asks a question.
2. The frontend sends the request to the backend.
3. The backend securely communicates with Google's Gemini API.
4. Gemini generates an educational response.
5. The response is returned and displayed in a conversational interface.
